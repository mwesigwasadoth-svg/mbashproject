# Zmotto

A responsive university digital-library interface built with React and Vite. Students can browse and search sample materials, save items, view document details, comment, and share. An upload form demonstrates the admin upload experience.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`.

## Demo limitations

This is a front-end prototype. Sign-in is simulated, and uploads, comments, saved documents, downloads, and sharing are not connected to a backend or persistent storage. Do not use real credentials. Production use requires secure university authentication, server-side authorization, file storage and validation, and persistent database services.
